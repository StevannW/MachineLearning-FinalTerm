# Project Summary

Repositori ini berisi tiga proyek machine learning dan deep learning yang mencakup berbagai domain analisis data:

## 📊 Project 1: Fraud Detection System

**Deskripsi:**
Sistem deteksi fraud end-to-end yang memprediksi probabilitas transaksi fraudulent menggunakan data transaksi dan identitas.

**Highlights:**
- **Dataset:** Transaction data & Identity tables
- **Tugas:** Binary Classification (Fraud vs Non-Fraud)
- **Workflow:**
  - Data cleaning & preprocessing
  - Feature selection/engineering
  - Model training (ML/DL)
  - Hyperparameter tuning
  - Evaluation dengan metrics yang sesuai (Precision, Recall, F1-Score, AUC-ROC)

**Teknologi:** Scikit-learn, XGBoost/LightGBM, Neural Networks, SMOTE/Class weighting

---

## 📈 Project 2: Regression Model

**Deskripsi:**
Model regresi end-to-end untuk memprediksi variabel target kontinu dengan fokus pada preprocessing dan feature engineering.

**Highlights:**
- **Tugas:** Regression (Continuous value prediction)
- **Workflow:**
  - Data cleaning & exploration
  - Preprocessing pipeline
  - Model training (ML/DL algorithms)
  - Basic hyperparameter tuning
  - Evaluation & interpretation (MSE, RMSE, MAE, R²)

**Teknologi:** Linear Regression, Random Forest, Gradient Boosting, Neural Networks

## 🖼️ Project 3: Image Classification with CNN

**Deskripsi:**

**Highlights:**

- **Workflow:**
